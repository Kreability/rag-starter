RAG URL Ingestion Test

This is a test HTML page for URL ingestion. The RAG system should fetch this page, extract the text, and make it searchable.

Section 1: Introduction

Retrieval-Augmented Generation (RAG) is a technique that enhances large language models by retrieving relevant information from external sources.

Section 2: How It Works

When a user asks a question, the system searches through the document chunks to find the most relevant passages and uses them to generate an accurate answer.

Section 3: Benefits

RAG reduces hallucinations, provides up-to-date information, and allows users to verify answers with source citations.
